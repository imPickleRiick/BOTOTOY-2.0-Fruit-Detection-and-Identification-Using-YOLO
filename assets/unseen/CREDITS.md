# Unseen test photos (not from the project dataset)

Twelve photos from [Wikimedia Commons](https://commons.wikimedia.org), downloaded on 2026-11-17 at 1024 px width.
All are **public domain or CC0**, so they can be stored and shown with this project. They were never part of
the training, validation or test data. They are used by `python -m src.evaluation.system_test` to check the
system on genuinely new images.

`expected.csv` lists the fruit types visible in each photo, determined by visual inspection (not by the model).
