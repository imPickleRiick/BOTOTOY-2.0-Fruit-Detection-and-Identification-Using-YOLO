# Demonstration images

Eight photos copied from the **test split** of the project dataset
([lakshaytyagi01/fruit-detection](https://www.kaggle.com/datasets/lakshaytyagi01/fruit-detection),
CC0-1.0 public domain). They were never used for training or for choosing settings. They are offered in
the app as clearly labeled demonstration data, so the system can be shown without your own photos.
